# 🔵 군집 분석 실험실

고등학교 「데이터 과학」 **Ⅲ. 데이터 모델링과 평가 — 군집 분석 모델의 개념**을
시뮬레이션으로 직접 만져 보며 배우는 웹앱입니다.

> © 2026 티쳐무 · 모든 권리 보유 — 학교 수업 목적으로만 이용해 주세요. 자세한 내용은 [LICENSE](LICENSE).

## 학습 목표
- 데이터 속성에 대한 유사성을 측정하고 분석하여 군집을 형성할 수 있다.
- 군집 분석 결과의 의미를 해석할 수 있다.

## 화면 (탭 5 · 카드 19)
화면은 언제나 1280×720 한 장이라 **스크롤이 없습니다.** 창 크기에 맞춰 통째로 늘고 줄며, ← → 키로 넘깁니다.

| 탭 | 카드 |
|---|---|
| 💡 생각 열기 | 지도·비지도 학습 분류 / 할리갈리 카드 묶기(내 기준 ↔ 종류·개수 ↔ 🤖 컴퓨터) / 군집 분석 사례 3가지 |
| 🔵 군집 분석 | 군집 분석이란?(속성에 따라 군집이 바뀜) / 성적 데이터 손으로 군집화 / 계층적 vs 분할적 / **k-평균 시뮬레이터** / **계층적 군집(덴드로그램)** |

| 📄 정리·PDF | 확인 문제 10 / 핵심 정리 빈칸 / **전체 학습 내용 PDF 내려받기**(A4 6쪽, 내 활동 결과 포함) |

## 사용 방법
1. `dist/index.html` 을 더블클릭하거나 배포 주소를 엽니다(인터넷 없이도 열립니다).
2. 탭과 카드를 차례로 넘기며 활동합니다. 마친 활동에는 ✔ 가 붙습니다.
3. 마지막 탭에서 [📄 PDF 내려받기]를 누르면 학습 정리 PDF 가 저장됩니다. 공용 컴퓨터라면 끝나고 [🧹 내 기록 모두 지우기].

## 개발
```bash
npm install
npm start            # 개발 서버
npm test             # 계산·교과서 수치 시험
npm run check:syntax # 소스 전수 점검
npm run build        # dist/index.html 한 파일로 빌드 + 빌드 점검
```
Vite + 바닐라 JS. 그래프는 직접 그린 SVG, PDF 는 html2canvas + jsPDF(앱 안에 함께 묶음).
